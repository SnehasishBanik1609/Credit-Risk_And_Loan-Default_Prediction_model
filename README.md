Credit Risk and Loan Default Prediction

A Machine Learning project that predicts the likelihood of loan default based on borrower and loan-related financial information. The project was developed and experimented with using Google Colab.

📌 Project Overview

Credit risk assessment is an important application of Machine Learning in the financial sector. This project analyzes historical LendingClub loan data to identify patterns associated with loan repayment and default.

The model follows a complete Machine Learning workflow, including:

Data collection and preprocessing

Exploratory Data Analysis (EDA)

Feature selection and engineering

Data visualization

Model training

Model evaluation

Loan default prediction

📊 Dataset

The dataset used in this project is the LendingClub Loan Dataset, obtained from Kaggle.

🔗 Dataset:
https://www.kaggle.com/datasets/habiburrohman/lendingclub-loan-dataset

The dataset contains information about borrowers, loans, financial characteristics, and loan outcomes.
